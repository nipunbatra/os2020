# CS 301 · Operating Systems (2020)

Course website for CS 301 Operating Systems at IIT Gandhinagar, Semester I 2020–21 (from August 2020):
<https://nipunbatra.github.io/os2020/>

The site is a [Quarto](https://quarto.org) website in the same design as
[ES 667 Deep Learning](https://nipunbatra.github.io/dl-2026/). GitHub Pages serves this branch as it is, so the
site renders in place: every page's `.html` is committed next to its `.qmd`. After editing a page, run
`quarto render` and commit the result.

| File | Contents |
|---|---|
| `index.qmd` | Home: course facts, course record, module overview, questions, references, teaching assistants |
| `schedule.qmd` | Lectures: every class with its slides, lecture videos and class recordings |
| `labs.qmd` | Lab questions and solutions |
| `zine.qmd` | Student zines (files in `Zines/`) |
| `assessment.qmd`, `_dates.qmd` | Dates and assessed work |
| `feedback.qmd` | Student feedback |
| `lectures/`, `labs/` | Lecture slides, code used in class (`lectures/code/`), lab handout and lab code |
| `2021/` | Assignment 0 (`2021/assignment0/`), kept at its address |
| `lectures/index.qmd`, `labs/index.qmd`, `zine/index.qmd`, `feedback/index.qmd` | Redirects from the old site's addresses |
| `styles.scss`, `course.scss`, `rail.html`, `course-theme.html`, `course-tools.html` | Shared theme |
